# Sweeper-Maid 1.20.1 Forge 移植计划书

> 版本：1.0 | 日期：2026-08-07 | 状态：执行中
> 目标：将 dev/NeoForge-1.21.1（2.0.2）全部新功能移植到 dev/Forge-1.20.1 分支。

## 1. 背景

仓库已存在 `dev/Forge-1.20.1` 分支（原仓库 1.20.1 版，Forge 47.2.0 / Java 17 / 版本 1.1.2，仅有基础清扫功能）。本次将其升级为与主分支 2.0.2 功能一致的版本（分支版本号定为 2.0.2）。

## 2. 移植内容（与主分支 2.0.2 对齐）

1. 垃圾箱翻页 GUI（不重开界面换页、鼠标不重置）
2. 动态页数 + 全局排序
3. 大容量堆叠（`DUSTBIN_SLOT_CAPACITY`）
4. 全局掉落物过载自动清扫（事件计数 + 5 秒校正，默认阈值 500）
5. 经验实体收集 → 附魔之瓶（`XP_PER_BOTTLE`=10）
6. 本地化（en_us/zh_cn）+ 配置双语注释
7. 分支欢迎提示（登录消息）
8. 点击垃圾桶链接直接开箱（RUN_COMMAND；**1.20.1 客户端会弹确认界面，接受**）
9. GameTest（结构 `gameteststructures/empty.snbt`）

## 3. API 适配清单（1.20.1 Forge 47.2.0）

| 项 | 1.21.1 NeoForge | 1.20.1 Forge 改法 |
|---|---|---|
| 网络 | RegisterPayloadHandlersEvent + CustomPacketPayload | `NetworkRegistry.newSimpleChannel` + `SimpleChannel.registerMessage`（enqueueWork 主线程） |
| 菜单注册 | `MenuType` + `IContainerFactory` + `writeClientSideData` | `ForgeRegistries.MENU_TYPES` + `IForgeMenuType.create` + `NetworkHooks.openScreen(player, provider, buf -> ...)` |
| 存档序列化 | `SINGLE_ITEM_CODEC` / 组件 / `HolderLookup.Provider` | NBT 直存（`ItemStack.save/parse`，count 独立 int）；`SimpleContainer.createTag()/fromTag(ListTag)` 无 provider 签名 |
| 事件 | `net.neoforged.neoforge.event.*` | `TickEvent.ServerTickEvent`（按 phase 判断）、`MinecraftForge.EVENT_BUS`、`FMLClientSetupEvent` + `MenuScreens.register` |
| 注册总线 | modContainer.getEventBus() | `MinecraftForge.EVENT_BUS` + `IEventBus`（@Mod 构造注入） |
| 配置注册 | modContainer.registerConfig | `ModLoadingContext.get().registerConfig` |
| 客户端发包 | PacketDistributor.sendToServer | `CHANNEL.sendToServer` |
| ItemStack | copyWithCount / isSameItemSameComponents | `copy()+setCount` / `isSameItemSameTags` |
| 版本 | 21.1.224 / Java 21 | 47.2.0 / Java 17 / ForgeGradle 6 |

## 4. 测试方案

1. `gradlew compileJava`（JDK 17 toolchain）。
2. `gradlew runGameTestServer`：5 个 GameTest 全部通过。
3. 客户端 GUI 行为（翻页/确认弹窗）交人工验证。

## 5. 风险

- 首次构建需下载 Forge 47.2.0 依赖（在线，可能较慢）。
- 1.20.1 无组件系统，存档格式与 1.21.1 分支**不兼容**（1.20.1 分支的旧档可读，1.21.1 存档不可互用，属预期）。
- 点击开箱在 1.20.1 有确认弹窗（已确认接受）。
